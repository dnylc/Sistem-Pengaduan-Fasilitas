# Website Pengelolaan dan Pengaduan Fasilitas Program Studi Informatika

## Progress Pengembangan Tahap 1

Tahap 1 merupakan tahap awal pengembangan Website Pengelolaan dan Pengaduan Fasilitas Program Studi Informatika. Pada tahap ini, kegiatan difokuskan pada identifikasi kebutuhan sistem, perancangan awal database, serta penyusunan struktur direktori proyek sebagai dasar pengembangan website.

### 1. Identifikasi Kebutuhan Sistem
- Mengidentifikasi permasalahan dalam proses pengelolaan dan penyampaian pengaduan fasilitas Program Studi Informatika.
- Menentukan tujuan pengembangan website sebagai media pengelolaan fasilitas dan penyampaian pengaduan.
- Mengidentifikasi kebutuhan awal sistem yang akan dikembangkan.

### 2. Perancangan Struktur Folder Proyek
Menyusun struktur direktori awal website untuk mempermudah pengelolaan file dan proses pengembangan sistem.

Struktur folder yang telah dibuat:

```text
Sistem-Pengaduan-Fasilitas/
│
├── admin/
├── assets/
├── auth/
├── config/
├── database/
├── docs/
├── pelapor/
├── uploads/
└── index.php
```

Keterangan:
- `admin/` : Direktori untuk kebutuhan halaman administrator.
- `assets/` : Direktori untuk file pendukung tampilan website.
- `auth/` : Direktori untuk kebutuhan autentikasi pengguna.
- `config/` : Direktori untuk konfigurasi sistem.
- `database/` : Direktori untuk dokumentasi dan file basis data.
- `docs/` : Direktori untuk dokumentasi proyek.
- `pelapor/` : Direktori untuk kebutuhan halaman pelapor.
- `uploads/` : Direktori untuk penyimpanan file yang diunggah pengguna.
- `index.php` : File utama sebagai halaman awal website.

*Catatan: Pada tahap ini, direktori telah dibuat sebagai struktur awal proyek dan belum seluruhnya diisi dengan file implementasi.*

### 3. Perancangan dan Dokumentasi Database
- Menentukan rancangan awal basis data yang dibutuhkan oleh sistem.
- Menyiapkan file SQL sebagai dokumentasi struktur database.
- Menyusun rancangan tabel yang akan digunakan dalam pengelolaan data fasilitas dan pengaduan.

### 4. Inisialisasi Proyek dan Pengelolaan Versi
- Membuat repository GitHub dengan nama `Sistem-Pengaduan-Fasilitas`.
- Menghubungkan proyek lokal dengan repository GitHub.
